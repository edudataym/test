# 📱 "나의 귀족님 웰니스 집사" 앱 기획 초안

## 🎩 컨셉 개요

**"바쁜 현대의 귀족님, 집사가 건강을 책임지겠습니다"**

대영제국의 전통을 이어받은 귀족이지만, 현대 사회의 분주함 속에서 식습관이 흐트러진 사용자를 위한 AI 집사 앱. 우아하고 품위있는 톤으로 수분·식이섬유 섭취를 관리하고 장 건강을 개선합니다.

---

## 🤵 핵심 기능

### 1. AI 집사 "Sebastian"
- **캐릭터**: 영국식 집사, 공손하지만 단호한 어조
- **대화 예시**:
  - "주인님, 오늘 아직 물을 한 모금도 드시지 않으셨군요. 귀족의 품위는 건강에서 시작됩니다."
  - "저녁 식사에 섬유질이 부족해 보입니다. 제가 샐러드 한 접시를 권해드려도 될까요?"
  - "주인님의 장 건강이 심히 우려됩니다. 이대로는 저택의 명예가..."

### 2. 수분 섭취 관리
- **집사의 정중한 알림**: "차 한 잔 드실 시간입니다, 주인님"
- **귀족 레벨 시스템**: 수분 섭취량에 따라 "Baron → Viscount → Earl → Duke"
- **우아한 기록**: 차, 생수, 스파클링워터 등 음료별 분류

### 3. 식이섬유 추적
- **음식 사진 촬영**: AI가 자동으로 섬유질 함량 분석
- **집사의 평가**: "오늘 식단은... 아쉽습니다만, 내일은 더 나아지실 거라 믿습니다"
- **귀족의 장바구니**: 섬유질 풍부한 식품 추천 목록

### 4. 배변 활동 일지
- **우아한 표현 사용**:
  - "주인님의 일상이 원활하십니까?"
  - "저택의 위생 시설 사용 기록"
- **Bristol Stool Chart를 귀족풍으로**: 그래픽으로 정중하게 표현
- **건강 분석**: 패턴 분석 후 식단 개선 제안

### 5. 집사의 주간 보고서
- 매주 월요일 오전, 격식있는 보고서 형식
- "지난주 주인님의 건강 관리 현황을 보고드립니다"
- 개선점과 칭찬을 우아하게 전달

## 🎨 디자인 방향

- **컬러**: 딥 네이비, 골드, 크림색 (영국 귀족 저택 느낌)
- **폰트**: 우아한 세리프체와 깔끔한 산세리프 조합
- **UI 요소**: 문장(紋章), 왁스 인장, 깃털 펜 아이콘
- **애니메이션**: 집사가 편지 봉투를 전달하는 듯한 알림

---

## 💎 차별화 포인트

1. **민감한 주제를 유머러스하게**: 배변 활동을 우아하게 포장
2. **게이미피케이션**: 귀족 작위 시스템으로 동기부여
3. **LLM 활용**: 상황별 맞춤형 대화, 식단 조언
4. **공감대**: "바쁜 현대인"이지만 "건강은 챙겨야 하는" 사용자

---

## 📊 주요 화면 구성

1. **메인 홈**: 집사가 서 있는 저택 홀, 오늘의 미션 표시
2. **수분 트래커**: 우아한 물 잔 애니메이션
3. **식단 기록**: 식탁 위 접시 형태의 UI
4. **건강 일지**: 가죽 노트 느낌의 기록장
5. **집사와 대화**: 챗봇 인터페이스 (격식있는 채팅방)

## 🎯 타겟 유저

- 20~40대 바쁜 직장인
- 건강 관리 필요성은 느끼지만 재미가 없어서 작심삼일
- 유머러스한 접근을 좋아하는 사람들
- 영국 문화, 집사 컨셉에 호감이 있는 사용자

### 시나리오 1: 아침 시작
```
08:00 - [알림] "주인님, 좋은 아침입니다. 오늘도 건강한 하루를 시작하시죠."
08:30 - [알림] "아침 식사 전 물 한 잔, 어떠십니까?"
```

### 시나리오 2: 식사 기록
```
12:30 - 사용자가 점심 사진 촬영
       Sebastian: "오, 샐러드를 선택하셨군요. 훌륭한 선택입니다, 주인님!"
       [식이섬유 15g 자동 기록]
```

### 시나리오 3: 건강 일지
```
저녁 - 사용자가 배변 활동 기록
      Sebastian: "주인님의 일상이 순조로우시군요. 다행입니다."
      [패턴 분석 → 주간 리포트에 반영]
```

### 시나리오 4: 주간 보고
```
월요일 오전 - [푸시 알림] "주인님께 지난 주 건강 보고서가 도착했습니다"

보고서 내용:
"존경하는 주인님께,

지난주 귀하의 건강 관리 현황을 보고드립니다.

📊 주요 지표:
- 수분 섭취: 일평균 1.8L (목표 대비 90%)
- 식이섬유: 일평균 22g (우수)
- 규칙적인 생활 리듬: 양호

💡 개선 제안:
오후 3시경 수분 섭취가 부족한 경향이 있습니다.
티타임을 권해드립니다.

🏆 이번 주 성과:
Baron에서 Viscount로 승급하셨습니다!

귀족님의 건강한 일주일을 기대합니다.

- Sebastian"
```

## 🔔 알림 전략

### 알림 타입
1. **정중한 리마인더**: "주인님, 물을 드실 시간입니다"
2. **칭찬**: "오늘도 훌륭한 선택을 하셨습니다!"
3. **우려**: "주인님, 오늘 아직 기록이 없으시군요..."
4. **격려**: "어제보다 나아진 모습, 자랑스럽습니다"

### 알림 타이밍
- 아침 기상 후 (08:00)
- 수분 섭취 리마인더 (2시간마다)
- 식사 시간 (12:00, 18:00)
- 주간 리포트 (월요일 09:00)

### 알림 톤 조절
사용자가 설정 가능:
- **격식있음**: "주인님, ~하시는 것이 좋겠습니다"
- **친근함**: "주인님~ 물 마실 시간이에요"
- **엄격함**: "주인님, 이는 용납할 수 없습니다"

## 💬 Sebastian 대화 시스템

### 대화 카테고리

#### 1. 일상 관리
- 수분 섭취 독려
- 식단 조언
- 건강 체크

#### 2. 칭찬과 격려
- 목표 달성 축하
- 꾸준한 노력 인정
- 작은 개선도 칭찬

#### 3. 우려와 조언
- 부족한 부분 지적 (우아하게)
- 개선 방안 제시
- 장기적 건강 경고

#### 4. 잡담
- 영국 문화 이야기
- 날씨 얘기
- 집사의 일화

### 대화 예시

**사용자**: "Sebastian, 오늘 너무 바빠서 물도 못 마셨어"

**Sebastian**:
```
"주인님, 귀족의 바쁜 일정을 이해합니다만,
건강을 소홀히 하시면 더 큰 문제가 될 수 있습니다.

지금 당장 물 한 잔 드시는 것은 어떠십니까?
제가 타이머를 설정해드리겠습니다.

바쁜 일정 속에서도 건강을 챙기시는 것이
진정한 귀족의 품격입니다, 주인님."
```

## 📱 기술 구현 세부사항

### AI 집사 구현
- **LLM**: OpenAI GPT-4 또는 Anthropic Claude
- **시스템 프롬프트**: Sebastian 페르소나 정의
- **컨텍스트**: 사용자 건강 데이터 포함
- **톤**: 격식있고 우아한 한국어

### 음식 분석 AI
- **이미지 인식**: Google Vision API 또는 Custom Model
- **영양소 데이터베이스**: 한국 식품 영양성분 DB
- **섬유질 추정**: 음식 종류별 평균값 활용

### 데이터 구조
```typescript
interface User {
  id: string;
  name: string;
  nobleRank: 'Commoner' | 'Baron' | 'Viscount' | 'Earl' | 'Duke';
  dailyWaterGoal: number; // ml
  dailyFiberGoal: number; // g
}

interface WaterLog {
  userId: string;
  timestamp: Date;
  amount: number; // ml
  beverageType: 'water' | 'tea' | 'sparkling' | 'other';
}

interface MealLog {
  userId: string;
  timestamp: Date;
  imageUrl?: string;
  fiberAmount: number; // g
  description: string;
  sebastianComment: string;
}

interface HealthLog {
  userId: string;
  date: Date;
  bristolType: 1 | 2 | 3 | 4 | 5 | 6 | 7;
  notes?: string;
}

interface Conversation {
  userId: string;
  timestamp: Date;
  userMessage: string;
  sebastianReply: string;
}
```
